# AIC AI Sport Coach

A tool that analyzes an uploaded video of volleyball setting using pose detection (MediaPipe) and gives feedback on form.

## Setup
1. Clone the repo
2. python3 -m venv venv
3. source venv/bin/activate
4. pip install -r requirements.txt

Python 3.10 to 3.12 works.
